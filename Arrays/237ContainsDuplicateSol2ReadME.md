# The next approach:

The next way for doing is this is via set.

So what is a set?
    It is essentially a collection of variables/expressions which are unique in value.
    Note the word : unique--> It means there must be no repetition inside set.

    Example : A normal List might be something like
    num = [1,2,3,1,2,3,1,2,3]

    But set must be 
    num = {1,2,3}
    There must be no repetition

# So, we simply use the approach that if it is in the set --> we say hey! there's a repetition and we point it out.

# Otherwise , we leave it till the end
